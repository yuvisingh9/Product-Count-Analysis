# Product Count Analysis

## Project Overview
This project focuses on analyzing product data using Microsoft Excel. The objective is to count products by category, identify the category with the highest number of products, and practice Excel functions such as COUNTIF and COUNTIFS.

### Objective
- Count products by category.
- Identify the largest product category.
- Practice COUNTIF and COUNTIFS functions.
- Understand product distribution across categories.
- Analyze unique products and sub-categories.

### Tools Used
- Microsoft Excel
- GitHub

### Dataset
A small Superstore-style dataset containing 24 product records.

The dataset includes the following columns:

| Column | Description |
|---|---|
| Product ID | Unique identifier for each product record |
| Category | Main product category |
| Sub-Category | Product's sub-category |

### Analysis Performed
1. Product count by category.
2. Identification of the top category.
3. Category-wise percentage distribution.
4. COUNTIF formula implementation.
5. COUNTIFS formula implementation.
6. Unique product and sub-category analysis.
7. Bar chart visualization.

### Excel Functions Used

**COUNTIF**

Counts products that match a single condition.

```excel
=COUNTIF(Dataset!$B$2:$B$25,A4)
```

**COUNTIFS**

Counts products that match multiple conditions.

```excel
=COUNTIFS(Dataset!$B$2:$B$25,"Technology",Dataset!$C$2:$C$25,"Phones")
```

### Deliverables
- Product count table
- Top category identification
- Excel formulas
- Bar chart
- Dataset

### Conclusion
This project demonstrates how Excel can be used to perform basic product count analysis. COUNTIF and COUNTIFS help summarize product data, while charts make category-wise comparisons easier to understand.
